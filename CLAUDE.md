# Tycho Station

A local code factory, in Rust. Orient with `mise tasks` and `cargo run -q -p xtask -- help`; the documents index is `docs/README.md`.
CUE before JSON before YAML; figures are stencil documents; logic lives in the xtask, never in shell or workflow files.
A mistake gets three things in one change: the fix, a ledger row, and the lowest-layer mechanism that catches it (`docs/process.md`). Done means `mise run ci` passed, or the report says why it did not run.
